
# COPY TO COPY 
[Secure Temporary File Sharing System]


## 🔍Project Overview
- COPY TO COPY is a live web-based file sharing application designed to solve a real-time problem faced by students during college lab sessions and examinations. 
- In many college labs, mobile phone usage is restricted, especially during tests and practical exams. At the same time, students often need to share documents, code files, or images quickly with friends. Existing platforms usually require personal logins, mobile access, or time-consuming authentication. 
- This project provides a simple, fast, and secure solution using temporary accounts, allowing file sharing without personal login or phone access. 

## 🎯Main Goal of the Project
The main goal of COPY TO COPY is to enable easy and secure file sharing during lab classes or test time by:

- Eliminating the need for personal login or registration
- Allowing access from any lab computer or device
- Using temporary accounts for controlled file access
- Ensuring only intended users can access shared files

## 🚨Real-Time Problem Statement
#### During college lab sessions:
- Mobile phones are not allowed.
- Login-based platforms waste time.
- Students cannot quickly share documents or program files.
- File sharing becomes difficult during exams or tests.

## 💡Solution Provided by COPY TO COPY
COPY TO COPY solves this problem by introducing a temporary account–based file sharing system:
- A temporary account is created instantly
- Files or photos are uploaded to that account
- Friends can access files using only the account name
- No phone, no personal credentials, no permanent account
- This makes the system fast, practical, and exam-friendly.

## 🔄How the System Works
- A temporary account is created during lab/test time
- User uploads documents or images to the account
- The account name is shared with friends
- Only users with the account name can access the files
- Files are stored securely on the live server

## ✨Key Features
- No login or registration required
- Temporary account-based access
- Secure file and image uploads
- Share files using account name only
- Responsive design (works on any device)
- Live server deployment
- Simple and user-friendly interface

## 🔐 Security Measures

- Server-side file validation
- Restricted upload directories
- Database-based file tracking
- No public access without account name
- Safe handling of documents and images
